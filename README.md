# Kylie LaCaze Personal Website

This website was created as part of my ISDS course at Louisiana State University using Google Antigravity IDE. The site serves as a professional portfolio highlighting my background in Information Systems and Analytics, internal audit, risk, data analytics, professional experience, skills, resume, and projects.

The website uses a hybrid structure with a single-page home page containing my profile, skills, experience, and contact information, along with separate pages for my resume and portfolio project.

## Reflection

One thing I did not understand at first was how one CSS file could control the design of several different HTML pages. I asked the Antigravity agent to explain how styles.css worked across my website. I learned that each HTML page loads independently and must link to the shared stylesheet. This allows the same colors, fonts, spacing, and other design elements to remain consistent across the entire website without repeating the styling code on every page. Understanding this helped me see how the different files in a website work together rather than functioning as completely separate pieces.
